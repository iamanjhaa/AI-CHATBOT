# 🤖 SAHAYAK — AI-Powered Real-World Problem Resolution Assistant

> **Understand Problems. Assess Situations. Guide People.**

SAHAYAK is an AI-powered problem-resolution chatbot designed to understand
real-world problems described by users in natural language and provide
relevant, situation-specific guidance.

Unlike a traditional chatbot that simply follows a
**Question → Answer** pattern, SAHAYAK follows:

**Problem → Understand → Analyze → Assess Risk → Solve / Clarify / Escalate**

It supports **English, Hindi, and Hinglish**, making it easier for users to
describe problems naturally.

---

## 🎯 Problem Statement

**SIH26043 — A digital platform to crowdsource societal challenges and
facilitate collaborative problem solving through universities and industry
partnerships.**

The goal is to create a platform where people can communicate real-world
problems and receive appropriate guidance while enabling collaboration between
citizens, educational institutions, industry, and government.

SAHAYAK acts as an intelligent problem-resolution layer for this ecosystem.

---

## ✨ Key Features

### 🧠 1. Natural Language Problem Understanding

Users don't need to use predefined commands.

They can simply describe their problem naturally:

> "Mere AC se paani leak ho raha hai."

SAHAYAK analyzes the message and understands the actual situation.

---

### 🔍 2. Intent Detection

SAHAYAK identifies what the user is trying to achieve.

Examples:

- Solution request
- Diagnosis
- Emergency assistance
- Civic complaint
- Helpline request
- Clarification

---

### ⚠️ 3. Severity & Risk Assessment

SAHAYAK evaluates the seriousness of the situation.

Possible severity levels:

- 🟢 LOW
- 🟡 MEDIUM
- 🔴 CRITICAL

For dangerous situations, the system prioritizes safety.

Example:

> "Mere geyser se spark ho raha hai."

SAHAYAK recognizes this as a potentially dangerous electrical situation
and avoids recommending risky DIY actions.

---

### 🛡️ 4. Safety-First Emergency Guidance

For critical situations, SAHAYAK switches from normal problem-solving to
safety-first guidance.

Examples:

- Gas leakage
- Electrical shock
- Live wires
- Fire
- Earthquake
- Dangerous appliance sparks
- Other potentially life-threatening situations

The system focuses on:

**Immediate Safety → Avoid Risk → Emergency Assistance**

---

### 🤔 5. Intelligent Clarification

If the user provides insufficient information, SAHAYAK does not simply
guess an answer.

Example:

**User:**

> "AC kharab hai."

**SAHAYAK:**

> "AC mein kya problem hai: cooling, awaaz, paani leak, ya power issue?"

This allows the system to provide a more accurate response.

---

### 🌐 6. Multilingual Support

SAHAYAK can understand:

- 🇬🇧 English
- 🇮🇳 Hindi
- 🔀 Hinglish

Users can communicate in the language they are most comfortable with.

---

### 🏙️ 7. Civic & Local Problem Assistance

SAHAYAK can understand community-related problems such as:

- Garbage accumulation
- Broken street lights
- Road potholes
- Drainage overflow
- Water supply issues
- Public sanitation problems

Example:

> "Mere area mein bahut kachra jama hai, complaint kahan karu?"

The system identifies this as a civic/reporting-related request and guides
the user toward the appropriate next step.

---

### ☎️ 8. Government & Emergency Helpline Directory

Users can request helpline information.

Examples:

> "All helpline numbers batao."

> "Government emergency numbers batao."

> "Mujhe helpline chahiye."

SAHAYAK provides available verified helpline information instead of allowing
the AI to invent phone numbers.

---

### 💬 9. Situation-Specific Responses

SAHAYAK does not rely only on fixed responses.

It considers the user's described situation and generates guidance relevant
to that particular problem.
